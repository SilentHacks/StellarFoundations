# StellarFoundations 0.5.0 (Preview)

Build stationary planetary bases with timber foundations. Start a level base on
adjustable piers, or anchor an existing structure without moving it or rebuilding
its floors, rooms, inventories and machinery.

- Automatically adapts to ground-contact floors or gaps up to six metres.
- Uses native build costs, holograms, tool hints and recycling.
- Short holds confirm anchoring and removal of a built structure's last support.
- Supports multiple anchors, damage, normal visitor docking and paired save recovery.
- Includes a separate-save export for removing the mod from a world.

**Requires StellarDrive Demo 0.8.2, MelonLoader 0.7.3 and SDModKit 1.3.3.**
Install these separately. Extract **StellarFoundations.zip** into the game folder,
or install through Stellar Mod Manager. The DLL goes in `Mods`.

Select **Foundation** in **Hull (Wood)**. Place it on terrain to start a base, or aim
at a floor and hold build to anchor an existing structure. Use the recycler on its
plate or floor mounting spot to remove it. The final support releases the structure.

**Preview scope:** single-player interactions and saves have been tested on
isolated worlds. Real remote co-op and extended normal-play testing remain open.
Multiplayer requires matching versions on every participant.

Back up the entire world directory before use or upgrading. Keep the mod installed
while a world contains foundations. Use **Save a separate copy without Foundations**
in the mod settings before removing it; the exported copy uses normal ship physics.
