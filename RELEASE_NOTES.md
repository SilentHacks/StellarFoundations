# StellarFoundations 0.6.4

- Foundation appears in the build menu after its runtime passes compatibility checks. Startup messages identify the incompatible mod, content pack or game build.
- Placement previews wait until the game's visual space is ready.
- Custom Seat 1.1.1, Arsenal 1.12.2 and Ship Schematics 1.0.3 are supported for placement and ordinary saves. These profiles may pause during a save. Export is unavailable while these mods save separate world data.

Requires Windows Demo 0.8.3, MelonLoader 0.7.3 and SDModKit 1.3.3. Back up the complete world folder before upgrading. Use the same Foundations version on the host and each client.

Build Zoop 1.6.1, Safety Rails 1.0.0 and StellarStriderLib 1.5.1 remain incompatible. Fusion and Warp10 profiles using that StellarStriderLib release are affected as well.
